# Redis 接入

在 **接入中心 → 新增实例 → 数据库 → Redis** 中添加实例。支持实例分组、标签、启停、编辑、删除及连接测试。

## 配置

| 字段 | 说明 |
| --- | --- |
| 接入地址 | `redis://cache.example.com:6379`；启用 TLS 使用 `rediss://cache.example.com:6379`，默认端口 6379 |
| 无认证 | 用于服务端未启用认证的实例 |
| 密码 | 对应 Redis 的密码认证；不用填写用户名 |
| ACL 用户名 | Redis 6+ 的用户名与密码认证 |
| 数据库编号 | 默认 DB 0，支持填写 0–65535 的整数，实际可用范围由服务端决定 |
| CA 证书 | 使用 `rediss://` 时可填写 PEM 格式 CA；留空使用系统信任证书 |

地址不包含用户名、密码、数据库路径或查询参数，这些字段在表单中分别配置。TLS 始终验证服务端证书和主机名，不自动回退到明文连接。

编辑时密码留空保留原值；切换认证方式需要重新填写对应凭据。选择无认证并保存会清除已保存的认证信息。列表和详情接口只返回密码已配置标记，不返回密码原文。

## 连接测试

测试建立真实 Redis 协议连接，完成认证、数据库选择并执行 `PING`，收到 `PONG` 才显示成功。DB 0 使用新连接的默认数据库；非零数据库通过 `SELECT` 选择。

测试账号需要 `PING` 权限，非零数据库还需要 `SELECT` 权限。测试不执行键写入、删除、清空数据库或配置修改，也不读取业务键值。认证失败、权限不足、数据库编号无效和 TLS 校验失败会分别提示。

接入 API 可通过已有的 `tunnel_id` 配置 SSH 隧道，TLS 仍按照目标 Redis 主机名校验。

## 当前范围

当前接入面向单实例或兼容单节点协议的服务端地址，提供连接管理与验证。尚未提供 Sentinel 主节点发现、Cluster 拓扑发现、键浏览或 Redis 命令工作台，因此不会作为 SQL 数据源出现在即时查询中。

认证及命令语义参考 [Redis AUTH](https://redis.io/docs/latest/commands/auth/)、[SELECT](https://redis.io/docs/latest/commands/select/) 和 [PING](https://redis.io/docs/latest/commands/ping/)。
