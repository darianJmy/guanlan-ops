# SQLite 数据库初始化

所有命令在项目根目录执行。业务数据库使用纯 Go SQLite 驱动，无需 MySQL 或 CGO。
数据库建表与初始数据已包含在应用中，正常部署不需要运行数据库初始化命令或导入 SQL。

## 全新数据库

默认文件为 `data/aiops.db`，父目录自动创建。只需运行发布的二进制：

```bash
./guanlan
```

自定义路径可通过 `--conf /etc/guanlan/config.yaml` 中的 `database.dsn`，或环境变量指定。例如：

```bash
export APP_DATABASE_DSN=/var/lib/aiops/aiops.db
./guanlan --conf /etc/guanlan/config.yaml
```

首次启动会在同一事务中创建表、索引、初始菜单、权限和管理员账号，并登记 SQLite 当前版本 `2026102701`。失败时整体回滚，下次启动可重试；并发首次启动会串行处理。已有当前版本数据库只校验版本，不重复写入初始数据或重置管理员密码。已有未知结构或不支持版本的数据库会报错退出，保留原数据。拨测任务菜单直接位于告警中心下，拨测规则组由用户自行创建。默认账号为 `admin / admin123`，首次登录后应修改密码。

SQLite 启用 WAL、外键约束、5 秒锁等待，并使用单连接串行处理写入。数据库目录需可写并持久化保存。运行期间的 `-wal` 文件可能包含尚未合并的数据；备份应使用 SQLite 备份工具，或停止应用后再复制数据库文件。

## 开发环境结构调整

当前只维护一套数据库结构，不提供旧版自动升级、历史字段回填或 MySQL 迁移脚本。
当前版本已移除旧证书管理表和自动化任务的证书部署字段。旧版本开发库会被拒绝打开；需要保留数据时先导出当前功能的数据，再导入新库。不需要保留数据时，在停止服务并确认数据库路径后重新创建开发库。不要只修改版本号来跳过结构校验。
已有数据库不会因重启而自动改写业务数据、菜单、权限或管理员密码。
